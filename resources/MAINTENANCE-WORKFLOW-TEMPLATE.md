# Property Maintenance Request — Workflow Template

A practical reference for recording and following a maintenance request from first report to accepted completion. Adapt the fields to the property manager's actual process.

## 1. Request record

| Field | Record |
|---|---|
| Request reference | |

| Issue summary | Describe the observable issue |
| Trade required | Plumbing, electrical, masonry, carpentry, other |

| Manager acceptance | Pending / accepted / needs follow-up |

Do not put tenant identity documents, access codes, private contact details or payment credentials in a public copy of this template.

## 2. Suggested status flow

1. **Reported** — the request has been received and recorded.
2. **Assigned** — a responsible technician or service provider has been selected.
3. **In progress** — work has started.
4. **Awaiting approval** — work is reported complete and awaits review or acceptance.
5. **Completed** — the completion has been reviewed and accepted.

A cancelled or rejected request should be recorded separately with a reason and an activity note.

## 3. Handover checklist

- Is the issue described clearly enough for the assigned trade?
- Is urgency recorded with a reason?
- Is the responsible person identified?
- Is the next action and due date clear?
- Are estimated and actual costs kept separate?
- Are completion notes and acceptance recorded?
- Is there an activity history for important status changes?

## 4. Safety and privacy

This template is an administrative aid, not a safety assessment or emergency service. Escalate immediate hazards to the appropriate emergency service or qualified professional. Collect only the information needed to manage the job and keep sensitive records in an access-controlled system—not in a public repository.
