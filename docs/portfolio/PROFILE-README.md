## What work do I focus on?

I help make day-to-day work easier to organise, maintain and improve.

- **Web and WordPress:** website implementation, maintenance, WooCommerce support and SEO improvements.
- **Digital operations:** coordination, documentation, follow-ups, tracking and practical team workflows.
- **Business tools:** lightweight dashboards and applications that make a process easier to manage.
- **AI-assisted workflows:** exploring useful applications of AI and automation where the task and limitations are clear.

## What can you explore?

More project documentation will be added as work is prepared for public review. Items that are still private, incomplete or not independently demonstrable will not be presented as published products.

## How do I approach a project?

Start with the real problem, make the workflow visible, build the smallest useful solution, document how it works and be honest about what it does not yet do.
