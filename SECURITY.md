# Security Policy

## Scope

This repository contains an early browser-based prototype. It is not designed to store sensitive tenant, property-access, payment or identity information.

## Do not submit

- Passwords, access codes, API keys or authentication tokens.
- Tenant identity documents or private contact details.
- Bank, card, payment or other financial credentials.
- Private property-access instructions.
- Confidential client data or personal information.

## Reporting a concern

Do not publish sensitive details in a public issue. Contact the project maintainer privately at paulchumbow254@gmail.com with a concise description and steps to reproduce the issue.

## Current limitations

The prototype uses browser localStorage and does not provide server-side authentication, shared access controls, encrypted server storage or managed backups. Do not rely on it as a secure record system.
